Manga Loud: the app and the setup steps

An Android app that reads manga, manhwa and webtoon speech bubbles aloud and acts them. For anyone who reads comics on an Android phone.

Quick start

  1. On your Android phone, open the Manga Loud repo on GitHub, go to Releases, and download mangaloud-0.1.0.apk.
  2. Open the file and allow installs from this source when Android asks, then open Manga Loud.
  3. Open Settings › Text recognition, choose Claude API, paste your Claude API key, then open the demo chapter (link below) and tap Read aloud.

What it is

Manga Loud is a browser for comic pages that reads the speech bubbles aloud. Claude reads each page and returns every bubble's text, who says it, the tone and how strong it is (1 mild, 2 clear, 3 extreme). A voice then acts each line: shouts louder, whispers quieter, thoughts a little softer. Before each line the page glides to the bubble and highlights it.

It is free and open source (GPL-3.0). Arul built it. It ships with no comics and no comic sites: use it only with comics you are allowed to read.

Before you start

  • An Android phone with Android 8 or newer. There is no iPhone version.
  • One way for Claude to read the pages (pick one):
  • Claude API: an API key from console.anthropic.com. It works anywhere and is paid per use, billed by Anthropic.
  • PC relay: your Claude Pro plan, Claude Code signed in on your computer, Node.js 20 or newer, and Tailscale on the computer and the phone. It uses your plan's usage limits, and the computer must be on.
  • What it costs: the app is free. Reading the text costs your Claude API usage or your plan's limits. The phone voice is free and offline. Fish Audio has a free model, and ElevenLabs and Gemini need your own key and are billed by them. A chapter is cached on the phone, so reading it again costs nothing.

Step 1: Install the app

Download mangaloud-0.1.0.apk from the repo's Releases page on your phone and open it. Android asks once to allow installs from your browser or file app: allow it, then install. If you prefer a computer, connect the phone with USB debugging on and use the adb command under Try these.

Step 2: Let Claude read the pages

Open Settings (the gear) › Text recognition.

  • Claude API: choose Claude API, paste your key, and tap Test key.
  • PC relay: on the computer, get the repo (git clone, or Code › Download ZIP on GitHub), open a terminal in its relay folder and run node server.mjs. It prints a setup link. Open that link on the phone, or copy it and tap Settings › PC relay › Paste setup link.

Step 3: Pick a voice

Settings › Voice. The phone voice works straight away. For acted sounds, choose Fish Audio and add a Fish Audio API key: a cough, a sigh or a laugh is then acted as a real sound before the words. ElevenLabs and Gemini work the same way with their own keys. Leave "Phone voice if this one fails" on, so reading never stops.

Step 4: Hear it on the demo chapter

Open the demo chapter in the app (link below) and tap Read aloud. It is a short comic made for the project, with a shout, a whisper, a thought, narration, a game window and a cough, so you hear each kind of line.

Try these

  • Install from a computer: adb install -r mangaloud-0.1.0.apk
  • Get the relay: git clone https://github.com/Aarul5/mangaloud
  • Start the relay: cd mangaloud/relay then node server.mjs
  • Start the relay at sign-in on Windows: powershell -ExecutionPolicy Bypass -File relay\install-autostart.ps1
  • Japanese manga: Settings › Reading › Right to left
  • Keep further ahead of the voice: Settings › Reading › Slices sent to Claude at a time › 8
  • Skip quest and stat windows: Settings › Reading › Read game windows › off
  • Give one series its own voices: ⋮ › Voices for this series

Gotchas

  • Android only, installed from an APK (not from the Play Store).
  • The PC relay listens on your Tailscale address only. If reading stops away from home, check Tailscale is on, on both devices.
  • If a cloud voice fails (no key, no signal, out of credit), the phone voice reads that line and the app says why once.
  • The phone voice can't cough or sigh: it leaves a short pause for those.
  • To undo: uninstall Manga Loud like any app (hold its icon › Uninstall). Delete your API keys in the provider's console if you no longer need them. On Windows, remove the relay's start-up task with relay\uninstall-autostart.ps1.
